## What's Changed

### Features

- **Deterministic, alias-free YAML output**: Mapping-based writes now expand repeated
  dictionaries and lists instead of emitting automatic YAML anchors and aliases. Equal
  acyclic values serialize the same way regardless of Python object identity, cycles
  raise an actionable `YamlSerializationError`, and low-level helpers retain an
  `allow_aliases=True` opt-in.
- **In-memory frontmatter splitting**: The new `fmf_split_frontmatter` API returns raw
  metadata plus exact character offsets into the original string. It supports every
  frontmatter style, LF, CRLF, and CR line endings, hash-style preambles, and a
  non-strict mode for unmatched opening delimiters.

**Full commit history**: https://github.com/jlevy/frontmatter-format/compare/v0.3.0...v0.4.0
