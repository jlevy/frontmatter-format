`_c_eligible` computes the exact `_nesting_bound` on every text. A cheap upper bound decides most texts first: rough = count("[") + count("{") + count("-") + count("?") + 2; if rough <= _C_SCAN_DEPTH and " " * ((_C_SCAN_DEPTH - rough) // 2 + 1) is not in the text, then the exact bound is <= _C_SCAN_DEPTH (flow <= the opener count, chain <= the indicator count, every indent run is shorter than that run of spaces). Otherwise fall back to the exact bound.

Measured (prototype): ~1 us instead of 8-29 us on typical frontmatter; all 76 bead files take the fast path; same decision on the 400,286-text differential. About 4% of a typical C-first read together with the regex rewrite. Size S. Safe: same decision by construction.
